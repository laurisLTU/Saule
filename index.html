About Saule

Saule is a lightweight programming language project focused on simplicity, terminal tools, file utilities, and clear syntax ideas.

  • Written in C
  • Built for terminal scripting
  • Runs `.saule` scripts
  • Includes file tools, browser tools, and simple flow control
