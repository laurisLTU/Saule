Saule Ebook

A practical guide to the Saule language, its syntax, commands, file tools, browser tools, and current capabilities.

1. What is Saule?

Saule is a programming language project written in C. It is focused on terminal usage, small scripts, text tools, browser tools, file editing, and experimentation.

2. Build and run

cd Saule
make
./saule

Run a Saule file:

./saule programa.saule
./saule browser.saule
./saule fileeditor.saule
./saule viewtxt.saule

3. Basic printing

print("Hello")
print("Welcome to Saule")

4. Variables

Saule supports `local` and `let` for assigning values.

local name = "User"
print(name)

let city = "ExampleCity"
print(city)

5. Math and calculator

Saule supports simple arithmetic with `+`, `-`, `*`, `/`.

calc(2+2)
calc(8*5)
calc(10-3)
calc(12/4)

local a = 10
local b = 5
calc(a+b)
print(calc(7+8))

6. Input

input name
print(name)

The REPL will ask for a value and store it in the variable.

7. If statements

if 1 then print("true")
if 0 then print("yes") else print("no")

local ready = 1
if ready then print("ready") else print("not ready")

8. While loops

Saule currently supports a simple `while ... do ...` form.

local loop = 1
while loop do print("loop works")
local loop = 0

There is a safety guard to avoid endless loops.

9. Functions

Saule supports one-line functions using `function name = command`.

function hello = print("Hello from function")
hello

function makefile = writetxt("projects/example.txt", "Hello")
makefile

10. Text file tools

You can create, write, append, and view text files.

writetxt("projects/example.txt", "Hello")
appendtxt("projects/example.txt", " world")
viewtxt("projects/example.txt")

11. File editor script

The built-in `fileeditor.saule` script asks for a full path and text, writes the file, then shows it.

./saule fileeditor.saule

12. Directory tools

mkdir("projects")
exists("projects")
exists("projects/example.txt")

13. Browser tools

Saule includes two browser-related commands:

  • `browse(...)` fetches a web page and prints cleaned text
  • `browse-inweb(...)` opens a URL in the system web browser
browse("https://example.com")
browse-inweb("https://example.com")
